# Autismo-VC-Bot
A Discord bot that sits in voice chat and has some basic slash commands using Discord.py. Used mainly in the r/autism Discord but can be selfhosted and used in other servers. Open source cuz why not.

# Commands:
- /autismo - pings the user that ran it with a custom emoji, as defined by the CUSTOM_EMOJI_NAME_AUTISMO env var
- /help - lists all available commands
- /gnorp - outputs the emoji defined by the CUSTOM_EMOJI_NAME_GNORP env var
- /tictactoe - allows a user to play tic tac toe against another user or the bot
- /uptime - shows the bot's uptime
- /connect4 - allows a user to play connect4 against another user or the bot
- /why - explains why I made the bot
- /teddy - allows a user to give a teddy bear emoji to another user
